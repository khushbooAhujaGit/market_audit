# Market Audit – Updates (2 Oct 2026)

Deployed to live: `marketaudit.escrips.in`

## 1. Complete / Reopen a project

- The **Projects** page has a new **Status** column (Open / Completed).
- Each row has a **Complete / Reopen** button.
- A project can be marked completed **only if at least one auditor is assigned** to it.
- The admin can reopen a completed project at any time.
- **No data is deleted.** Assignments, answers and pending verifications come back exactly as they were on reopen.
- New columns in `projects`: `is_completed`, `completed_at`, `completed_by`. They come from the migration `2026_10_01_000001_add_is_completed_to_projects`.

## 2. Hiding completed projects

| Area | Behaviour for a completed project |
|---|---|
| Auditor APK | Removed from the project list. All project/row APIs return `403` with `"project_completed": true`. |
| Auditor web panel | Hidden from **My Projects**. Project pages redirect back with a "project completed" message. |
| Verifier | Removed from **My Verifications**. Verify pages and Approve/Reject are blocked. |
| Super Admin | Never blocked. |
| Reports | Still available (see section 3). |

The APIs blocked on the APK side: activities, questions, save/submit/finalize answers, image and signature upload, repeat instances, close activity, close audit, OTP, and template data.

Direct access to a completed project is blocked by the new `project.active` middleware (`EnsureProjectNotCompleted`). It is applied to 22 API routes and 23 web routes.

## 3. Reports: Open / Completed switch

- There is an **Open Projects / Completed Projects** switch on:
  - **Report Dump**
  - **Project Report**
  - **PDF Report**
- It applies to every role: Super Admin, Verifier, Company User and Agency.
- The default view shows open projects.
- In the dropdown, completed projects are labelled **"(Completed)"**, and a "Showing completed projects only" note appears under it.
- Fixed: the switch link was being encrypted by the app's URL generator, so it now builds a plain `?view=completed` URL. Encrypted links still work too.

## 4. Verifier view for Barcode / QR Code / RFID answers

- Scan answers now show as a readable table instead of raw JSON. The table shows:
  - each expected header and its value;
  - missing headers;
  - extra keys;
  - the raw scanned value.
- Fixed: scan answers under Multi Response sub-questions were being shown as broken images.

## 5. Other fixes

- **Projects page:** the Complete button text was invisible because of the theme's styling, and now has its own style.
- **Report Dump and Project Report:** the verifier/agency project query mixed AND and OR without brackets. It is now grouped correctly, and the list of projects users see is unchanged.


Do **not** upload the local `.env` file. Production must keep `APP_URL=https://marketaudit.escrips.in` and `SESSION_DOMAIN=marketaudit.escrips.in`.
